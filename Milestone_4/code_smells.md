## How did refactoring improve the readability and maintainability of the code?

- Refactoring simplified the logic, reduced duplication, and made responsibilities clearer. The code is now easier to read, understand, and extend without confusion.

## How can avoiding code smells make future debugging easier?

- It reduces complexity and clutter resulting in easier to read code and address bugs efficiently. It provides clean consistent codes that developers quickly understand the flow and resolve problems.
